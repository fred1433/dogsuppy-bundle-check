        The same check, every morning

        The sheet at the top is what this view returns on the snapshot. It is one of four; each returns one row per problem and nothing when all is well, with the same columns: check_name, severity, store, key, expected, actual, delta, evidence_url, read_at. A rule that cannot run on a row returns it as not_checked, never as a pass.
